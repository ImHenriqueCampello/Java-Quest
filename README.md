# Java Quest: The Bytecode Chronicles

## Sobre o Projeto

O **Java Quest: The Bytecode Chronicles** é um RPG de combate em turnos executado no terminal, concebido para transformar o aprendizado da linguagem Java e dos fundamentos da computação em uma jornada envolvente e interativa.

No jogo, o jogador assume o papel de um desenvolvedor desbravador que ascende pelas camadas da Java Virtual Machine (JVM). Ao longo do percurso, enfrenta falhas clássicas de programação personificadas como criaturas — desde o *NullPointer Imp* e a *Infinite Loop Serpent* até o imponente *StackOverflow Dragon*. O objetivo do projeto é consolidar conceitos essenciais da engenharia de software e da JVM de forma prática, unindo a estética clássica dos RPGs retrô ao universo do desenvolvimento.

## Experiência

A experiência alia estratégia de combate por turnos à resolução ativa de problemas. A cada rodada, o jogador desfere ataques conjurando magias de código, respondendo a desafios reais que cobrem desde tipos primitivos e estruturas de repetição até polimorfismo, tratamento de exceções e gerenciamento de memória.

Respostas corretas constroem sequências de combo que amplificam o dano dos ataques, enquanto erros abrem espaço para contra-ataques inimigos e trazem explicações técnicas imediatas sobre o comportamento da linguagem. Para enriquecer a tática, o jogador administra sua barra de mana com habilidades de depuração inspiradas no dia a dia da programação — aplicando refatorações para restaurar pontos de vida, acionando breakpoints para descartar alternativas incorretas e erguendo barreiras try-catch para mitigar danos. Com renderização dinâmica em arte ASCII e feedback em tempo real, o aprendizado se torna uma consequência natural da jogabilidade.
