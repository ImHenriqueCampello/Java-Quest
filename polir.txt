SUMÁRIO EXECUTIVO
--------------------------------------------------------------------------------
O Java Quest é um RPG de terminal em Java 27 extremamente criativo e carismático,
unindo combate em turnos com temática de desenvolvimento e engenharia de software Java.
A mecânica de idle animation em tempo real sobre a pergunta (introduzida recentemente
com ANSI DEC/SCO cursor save/restore) elevou consideravelmente o nível técnico do projeto.

Contudo, para transformar este projeto em uma experiência memorável, de padrão
comercial indie de terminal ("CLI Masterpiece"), existem áreas estratégicas que podem
ser refinadas. Este documento detalha cada uma dessas frentes com soluções práticas,
diagramas e exemplos de implementação.

- Como implementar no terminal:
  Alternar rapidamente pequenos deslocamentos horizontais com códigos ANSI:
  ```java
  public static void screenShake(int intensity, int durationMs) {
      for (int i = 0; i < intensity; i++) {
          System.out.print("\033[1C"); // Move cursor 1 coluna à direita
          sleep(durationMs / (intensity * 2));
          System.out.print("\033[1D"); // Move cursor 1 coluna à esquerda
          sleep(durationMs / (intensity * 2));
      }
  }
  ```
  Ou piscar a tela inteira com inversão de vídeo (`\033[7m` seguido de `\033[27m`).
